ANIMATIONS — THE CORE "WOW" FACTOR
═══════════════════════════════════════════

The animations are what will make the client accept without negotiation. They must feel calm, tactile, and premium — like turning pages of a beautiful book, NOT like a tech demo.

Philosophy: The user should FEEL the smoothness, not see the effects. Every motion should feel like paper, silk, or ink — organic, not mechanical.

1. HERO ENTRANCE (on load, staggered):
   - Eyebrow → headline → subline → CTA1 → CTA2
   - Each: opacity 0 → 1, translateY 24px → 0, 800ms ease-out
   - Stagger by 150ms
   - Headline reveals line-by-line (not letter-by-letter)

2. HERO IMAGE:
   - Continuous slow drift: scale 1.0 → 1.05 → 1.0 over 22 seconds, infinite
   - Subtle horizontal drift ±1%
   - On scroll: parallax at 0.85x scroll speed (image moves slower than page)
   - Container: position relative, overflow hidden

3. PAPER GRAIN OVERLAY:
   - Fixed full-page SVG noise overlay at 4% opacity
   - Never animates — but gives the site a tactile, physical feel

4. FLOATING PAPER ELEMENTS:
   - 2–3 subtle SVG shapes (a paper corner, a wax seal outline, a folded card silhouette) floating gently in the hero and workshops section
   - Opacity: 6–10%
   - Slow float: translateY ±12px, rotate ±3deg over 12–16 seconds
   - Different delays per element
   - Hidden on mobile

5. SCROLL REVEAL (sections):
   - opacity 0 → 1, translateY 30px → 0, 800ms ease-out
   - Trigger once per section via IntersectionObserver

6. IMAGE REVEAL (curtain effect for portfolio tiles):
   - clip-path: inset(0 0 100% 0) → inset(0 0 0% 0)
   - 1100ms ease-out
   - Combined with opacity 0 → 1
   - Stagger tiles by 120ms

7. TYPOGRAPHY REVEAL:
   - Large serif headings reveal word-by-word (NOT letter-by-letter)
   - Each word: opacity 0 → 1, translateY 14px → 0, 500ms
   - Stagger 70ms

8. HOVER MICRO-INTERACTIONS (desktop only):
   - Service tiles: background shifts to warm cream over 300ms, icon rotates 3deg
   - Portfolio images: scale 1.03 over 600ms ease-out
   - Links: underline draws in from left over 300ms
   - Buttons: subtle translateY(-2px) + soft shadow over 250ms
   - CTA arrow icons: shift 4px right on hover

9. NAVBAR:
   - On scroll past 40px: background fades to ivory, hairline bottom border appears, height reduces slightly — smooth 300ms transition

10. ENQUIRY MODAL:
    - Backdrop: fade in 200ms
    - Modal: scale 0.97 → 1.0, opacity 0 → 1, 250ms ease-out

11. REDUCED MOTION:
    - Wrap all animation in @media (prefers-reduced-motion: no-preference) OR add a reduce block that disables everything
    - When reduce is on: keep opacity transitions only, no transforms
